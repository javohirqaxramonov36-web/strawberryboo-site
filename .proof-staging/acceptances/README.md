# Private acceptance-proof staging

This folder contains **six flattened, low-resolution, watermarked, reconstructed previews** derived from verified acceptance letters. They are private staging derivatives only: no originals, raw text extracts, metadata copies, or source URLs are included.

## Safety treatment

Each preview retains only the institution name, a positive decision phrase, the stated program, and the enrollment year. All applicant identity, identifiers, contact details, addresses, full dates, signatures, URLs, QR/barcodes, financial details, and conditions/requirements detail are absent by construction. The University of Birmingham preview retains only the minimal **“Conditional offer”** qualifier needed to avoid misrepresentation.

Every image is a flattened raster derivative with an embedded watermark: **“REDACTED PREVIEW • PRIVATE STAGING • NOT AN ORIGINAL.”** It is not a copy or visual excerpt of the original letter.

## Verification completed

All six PNG previews were visually reviewed as a contact sheet and independently OCR-checked for prohibited content. Each passed the check: no applicant identity, contact data, address, full date, identifier, signature, URL, QR/barcode, monetary figure, or detailed condition/requirement is visible. The paired WebP files are encodings of the same flattened image content.
