# Payment and access SOP
1. Confirm the learner’s chosen course and current public price from its page.
2. Share payment details only in the direct Telegram conversation; never request card PIN, CVC, or passwords.
3. Confirm the receipt and payment before sending the applicable access link manually.
4. Record only the minimum operational note needed to resolve access questions; do not put payment details in this repository.
5. If information differs from the public page, pause and correct the public source before promising access.
