## Hero comparison
Use a **sequential comparison** first: run hero A for one defined period, then hero B for a comparable period; record traffic source and dates. This avoids silently changing visitor experience.

An optional static-JS randomized version may be added only after owner approval. It must have an enable/disable configuration, assign a stable variant in localStorage, and emit a guarded GA4 event only when the existing analytics guard is active. Do not enable it by default.
