# SAT Math — formula cheat-sheet

- Chiziqli funksiya: `y = mx + b`
- Qiyalik: `m = (y2 − y1) / (x2 − x1)`
- Kvadrat tenglama: `ax² + bx + c = 0`
- Diskriminant: `b² − 4ac`
- Foiz o‘zgarish: `(yangi − eski) / eski × 100%`
- Uchburchak yuzi: `A = 1/2 bh`
- Doira: `C = 2πr`, `A = πr²`
- Pifagor: `a² + b² = c²`
- O‘rtacha: `sum / count`

Formulani yodlashdan oldin masala nimani so‘rayotganini va birliklarni tekshiring.
