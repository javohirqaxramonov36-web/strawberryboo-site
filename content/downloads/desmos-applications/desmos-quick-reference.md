# Desmos — SAT quick reference

1. Grafik oynasini oching va o‘qlarni tekshiring.
2. Tenglamalarni alohida qatorda kiriting.
3. Kesishish nuqtasini topishda grafikni kattalashtiring.
4. Jadvaldan qiymatlarni tekshiring.
5. Desmos javobni tekshiruvchi vosita; masala ma’nosini tushunishni almashtirmaydi.
